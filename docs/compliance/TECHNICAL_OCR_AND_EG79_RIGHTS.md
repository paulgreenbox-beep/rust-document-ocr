## EG79 role and release decision

EG79 is a preserved, optional technical OCR model, not the title-block detector itself. The core title-block path does not invoke the special EG79 recheck; only the relevant explicitly routed OCR path can use the model. Retaining the weights in packaging therefore must not be described as EG79 handling every stamp or every title block.

The selected weight identity is unchanged in the retained original RC1 package and the pure-HEIC package. This confirms preservation, not permission to distribute. Current posture: **EG79 — RETAINED; PUBLIC WEIGHT DISTRIBUTION — BLOCKED / RIGHTS UNKNOWN.** No model upload, retraining, threshold change, or training-corpus publication is authorized by this review.
